Forever, turned all the way up.

The graphics menu stops short of what the engine can draw. Paste these into chat once and Azeroth gets thick grass to the horizon, distant hills that keep their shape, and water that reflects the trees.

Click a line to copy it, paste it into chat, press Enter. Chat runs one line at a time.

Settings save to WTF/Config.wtf in your _forever_ folder. Copy that file somewhere first; if anything goes wrong, put the copy back.

Make it look better

Do these in order. The commands above only add detail on top of the in-game preset, so the preset comes first.

  1. Set the graphics preset to 10

    Options → Graphics. A modern high-end card runs everything at maximum, including Secondary Lighting, Compute Effects and SSAO, which are the settings that draw the new fog and moonlight. Keep Render Scale at 100%.

  2. Paste the hidden commands

    Each one pushes a setting past where its slider stops.

    CommandWhat changes
    groundEffectDensity 256Grass and flowers. The menu maximum is 48; 256 turns the Barrens and Elwynn into real fields. Drop to 128 if frame rate suffers.
    groundEffectDist 500Grass is drawn out to 500 yards instead of about 200.
    groundEffectFade 370Grass fades in gently at the edge instead of popping.
    lodObjectFadeScale 200Carts, wells, fences and signs stay visible from further away.
    lodObjectCullSize 8Small distant props stop being hidden.
    doodadLodScale 200Trees and rocks keep full detail further out.
    terrainLodDist 1000Distant hills keep their shape and textures.
    reflectionMode 3Water reflects trees, characters and mounts, not just the sky.
    weatherDensity 3Heaviest rain and snow. Storms last about 20 minutes.
    ResampleAlwaysSharpen 1Sharpening at 100% render scale. Forever looks soft without it.
    cameraDistanceMaxZoomFactor 4Lets the camera pull back about twice as far.

  3. Tune sharpness and colour

    After the sharpen command, set Resample Sharpness (bottom of Graphics) to about 0.6. Higher looks grainy.

    The new fog and lighting can take far more contrast than old WoW could. Start at:

    Contrast
    75–80
    Brightness
    48
    Gamma
    1.1

    Raise gamma, not brightness, if caves are too dark to see the floor.

  4. Smooth out frame pacing

    Turn vsync off, cap the foreground frame rate a few frames under your monitor's refresh rate (160 on a 165 Hz panel), and turn on low-latency mode. A capped game runs cooler and more evenly than one hitting 400 fps in Goldshire.

  5. Optional: RTX HDR

    On an HDR monitor with an NVIDIA RTX card, RTX HDR in the NVIDIA app works at the driver level without touching the game. Install the NVIDIA driver released for Forever on 4 November first.

What to skip

ReShade
Modern WoW has blocked ReShade's dxgi.dll since 2025, players report bans, and Forever runs on the same client. The commands above get most of the same look safely.
NVIDIA filters workaround
Alt+F3 filters stopped recognising Forever at launch. The anselintegrationtestapp.exe trick going around the forums breaks chat channels. Wait for a driver fix.
Ray Traced Shadows
Greyed out for everyone. Blizzard pulled it from the beta on 1 October and the client reports no ray tracing on any card. It isn't your hardware, and forcing the setting does nothing.
WeakAuras
No official Forever version. The combat rules from modern WoW stop addons from doing that kind of maths in combat. Use the built-in Cooldown Manager instead.

Built-in tools worth turning on

Forever ships features that used to need addons. Most are off by default. Tick them off as you go; this page remembers your ticks in this browser.

Addons

Forever only loads addon files built for it (interface 16001). Classic Era versions show as out of date. Every addon below has a Forever release on CurseForge.

Install or update them

Either pick WoW Forever as the game version in the CurseForge app and install each one, or run the script in this repo with the game closed. It fetches each addon's newest Forever file and copies only the folders that load in Forever.

From a clone of this repo, with Python 3 installed
python -I tools/install_addons.py "C:/Program Files (x86)/World of Warcraft/_forever_/Interface/AddOns"

Use one addon manager only. Two apps updating the same folder overwrite each other.

Worth a look later

  • Platynator or Plater for nameplates you can restyle.
  • EllesmereUI or ElvUI to replace the whole interface. Big change; try the built-in Edit Mode first.
  • RestedXP for step-by-step levelling routes. The addon is free; the Forever routes are paid.
  • AtlasLoot Classic Forever for loot tables while planning gear.

Still missing a Forever version: WeakAuras (community forks exist, expect breakage), Postal, OmniCC, Recount.
